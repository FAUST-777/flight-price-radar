# ✈️ flight-price-radar 機票價格雷達

每天自動監測「台北出發 → 日本/義大利各城市」的**直飛、來回、全服務航空**最低票價,
寫入 Google Sheet 留歷史,網頁(黑暗風格)隨時監看;低於目標價就亮紅標,看到好價直接下手訂票。

## 需求起因

想飛日本和義大利,但還沒規劃行程——不確定去哪個城市、哪天出發。
與其每天手動查票價,不如仿照 stock-tracker 的模式做一個「機票版」:

- 只看**直飛**(不轉機)、只看**來回票**(不看單程)、**不含廉價航空**(長榮/華航/星宇/日航/全日空等全服務航空)
- 日本、義大利**所有有直飛的城市全部列出來**,介面上按國家分類,方便比較「去哪裡最划算」
- 每天自動掃描未來 2 週~4 個月的出發日,找出每條航線最便宜的來回組合
- 網頁隨時看,**低於自設目標價亮紅標**,達到好價就買

## 資料來源

**Google 航班**(www.google.com/travel/flights)。
原本規劃用 Amadeus 免費 API,但其自助服務(Self-Service)已於 2026-07-17 全面下線、只剩企業簽約版;
Skyscanner 則無公開 API 且搜尋頁擋爬蟲(HTTP 307 → 驗證頁)。
Google 航班搜尋結果頁純 HTTP 就能取得,台幣計價、可帶「直達」條件,實測台灣出發航線資料完整。
**好處:整個專案不需要註冊、不需要任何 API 金鑰。**

## 架構

```
GitHub Actions(每天台灣時間 06:30)
  └─ scripts/scan.mjs
       ├─ 抓 Google 航班搜尋結果(直飛+來回),解析價格與航空公司
       ├─ 白名單過濾全服務航空、黑名單擋廉航(含日航掛名的捷星代飛班次)
       └─ 寫入 Google Sheet(prices / targets / log 三個分頁,自動建立)

Vercel
  ├─ public/index.html   網頁介面(黑暗風格、國家分類卡片、走勢圖、目標價紅標)
  ├─ api/prices.js       讀 Sheet → 整理成前端資料
  └─ api/target.js       網頁上修改目標價 → 寫回 Sheet
```

## 監測航點

| 國家 | 城市 |
|---|---|
| 日本(5 天行程) | 東京、大阪、名古屋、福岡、札幌、沖繩、仙台、熊本、廣島、高松、鹿兒島、函館、松山、小松、青森、北九州(16 個) |
| 義大利(10 天行程) | 羅馬 FCO(華航直飛)、米蘭 MXP(長榮直飛) |

全部城市每天掃描,每條航線取樣未來第 14~112 天、每 14 天一個出發日(共 8 組日期)。
查無直飛班次的日期會自動略過;整個城市都查不到就顯示「目前查無直飛報價」(例如季節性停飛)。

- 航空白名單:長榮、華航、星宇、日航、全日空、華信、ITA義航、星悅
- 廉航黑名單:虎航、樂桃、捷星、酷航、亞航、ZIPAIR 等——黑名單優先,
  所以「日航掛名、捷星代飛」這種班次也會被擋掉

## 設定步驟(第一次)

1. **Google Sheet**:建一個新的空白 Sheet,把既有的 Google 服務帳號加為**編輯者**,
   記下網址中的 Sheet ID。分頁不用建,掃描器會自動建立。
2. **GitHub Secrets**(repo → Settings → Secrets and variables → Actions):
   - `GOOGLE_SERVICE_ACCOUNT`(服務帳號 JSON 整份貼上)
   - `SHEET_ID`
3. **手動測試**:repo → Actions → daily-scan → Run workflow,跑完看 Sheet 有沒有資料。
4. **Vercel**:Import 這個 repo,環境變數設定同樣兩個值,部署完成即可。
5. 還沒設定好之前,網址加 `?demo=1` 可以看示範資料預覽介面。

## 注意事項

- 顯示的是 Google 航班查詢當下的最低報價,**訂票前請以航空公司官網為準**
- 每天約 144 次抓取、間隔 2.5 秒,對 Google 相當溫和;`log` 分頁記錄每日抓取量與錯誤
- 若某天 GitHub Actions 的機房 IP 被 Google 限制(掃描 log 會出現「同意頁」或「抓不到台幣價格」錯誤),
  備案是在自己電腦跑 `node scripts/scan.mjs`(環境變數見憑證庫),或換 self-hosted runner
- Google 航班改版可能導致解析失效(`pIav2d` 區塊標記、`新台幣` 價格標籤),
  屆時比對 `scripts/scan.mjs` 的 `parseOffers()` 與實際 HTML 即可修
- 目標價在網頁上就能改(存回 Sheet 的 `targets` 分頁),不用動程式碼
